# 网易云来源身份独立于 SMTC 会话

网易云的完整播放信息依赖内存读取，而 Store 版可能没有 SMTC，媒体控制又只能依赖其已有 SMTC 能力。因此以一个稳定的网易云来源承接两条通道：内存信息优先，SMTC 为可选补充，来源选择不再等同于选择 SMTC 会话。相比把内存仅作为“没有任何 SMTC 时”的兜底，这让它能够参与手动选择和现有自动跟随，同时避免重复来源及误用其他播放器的控制会话；隐藏这个来源时同时停止内存读取。

具体行为及验证记录见 [双通道设计](../store-netease-dual-source-design.md)。
