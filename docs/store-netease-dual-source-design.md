# 网易云音乐双通道接入

## 已确认行为

- 同一个网易云仅显示一个“网易云音乐”，不显示通道后缀；来源识别和手动选择不依赖 SMTC。
- 有效的内存曲目信息、进度、时长、播放状态与歌词优先。同来源 SMTC 补充已有播放控制，以及能够确认属于同一曲目的封面、歌词；内存不可用时回退到同来源 SMTC。
- 无 SMTC 时显示可用信息和歌词，不新增媒体控制方式，也不借用其他播放器的控制会话。
- 尊重手动选择，复用现有自动切换策略；浏览器的现有例外保持不变。
- 内存读取默认启动，不另设通道开关。启用来源过滤并隐藏网易云时停止读取、取消在途工作；重新允许后恢复。两个通道共用同一来源允许状态，兼容既有网易云 SMTC 允许项，不改变设置 JSON 字段或 schema。
- 暂停保留来源和信息。临时读取失败最多缓冲 3 秒，期间冻结进度并保持选择；超时清除失效内存信息，仍有同来源 SMTC 时可继续显示。内存发现的进程消失时立即撤下内存来源状态。
- 私人 FM 按歌曲 ID 命中可独立显示；缺少可靠信息时继续拒绝未经标题校验的队列索引兜底，不猜测曲名和歌词。

## 实现边界

- 来源候选使用稳定身份与可选 SMTC 会话键；选择身份不随 SMTC 出现、消失或重建而改变。
- 网易云作为已知来源保持可配置，避免停读后无法再通过设置重新允许。
- 内存读取使用已有窗口发现、进程扫描与本地元数据读取机制。读取器由后台循环独占并释放；新循环等待旧读取器释放，UI 回调检查取消与代次，UI 退出不阻止后台释放。
- 保留空闲降频、关屏或睡眠暂停、恢复后重启的资源管理策略。
- 元数据文件可能晚于曲目切换更新，因此未命中按 1 秒退避重试，不永久拒绝同一曲目；构造扫描失败也释放已打开的进程句柄。
